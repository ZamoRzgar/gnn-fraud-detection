## Core papers (required venues)

1. **FRAUDAR: Bounding Graph Fraud in the Face of Camouflage**
   Hooi, Song, Beutel, Shah, Shin, Faloutsos — **KDD 2016**, pp. 895–904
   (KDD 2016 Best Paper). Not on arXiv; get it from the author:
   - PDF: http://www.cs.cmu.edu/~christos/PUBLICATIONS/kdd16-fraudar.pdf
   - Project page: https://bhooi.github.io/projects/fraudar/index.html
   - DOI: https://doi.org/10.1145/2939672.2939747
   - Save as: `FRAUDAR_KDD2016.pdf`

2. **A Semi-supervised Graph Attentive Network for Financial Fraud Detection (SemiGNN)**
   Wang et al. — **ICDM 2019**, pp. 598–607
   - PDF: https://arxiv.org/pdf/2003.01171 ✔ already downloaded
     (`SemiGNN_ICDM2019.pdf`, 10 pages)
   - DOI: https://doi.org/10.1109/ICDM.2019.00070

3. **A Comprehensive Survey on Graph Anomaly Detection With Deep Learning**
   Ma, Wu, Xue, Yang, Zhou, Sheng, Xiong, Akoglu — **IEEE TKDE**, 35(12):12012–12038, 2023
   - PDF: https://arxiv.org/pdf/2106.07178
   - DOI: https://doi.org/10.1109/TKDE.2021.3118815
   - Save as: `GraphAnomalySurvey_TKDE2023.pdf`
